# Park Run

An abstract, jump-only skate runner for the web, built for a multisensory interaction design module. Every move is tied to a recorded skate sound: rolling, ollie pop, landing, rail and manual-pad slides, and the bail.

Play: https://pranjalru.github.io/park-run/

- Spacebar or tap to start and to jump
- Double tap for a kickflip or shove-it

Fonts: Array (Indian Type Foundry, Fontshare FFL) and Khand (OFL); licences included.
